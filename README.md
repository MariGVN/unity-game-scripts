# unity-game-scripts
Videojuego de titulacion 
Proyecto de Titulación — Videojuego en Unity

Descripción

Proyecto de desarrollo de un videojuego realizado como proyecto de titulación durante mi formación como Ingeniera en Tecnologías de la Información en la Universidad Técnica Particular de Loja (UTPL).

El proyecto fue desarrollado utilizando Unity y C#, implementando diferentes sistemas, mecánicas y elementos interactivos mediante programación.

Este repositorio contiene los scripts desarrollados en C# utilizados durante el desarrollo del videojuego, organizados según su funcionalidad.

Nota sobre los recursos: Los personajes, modelos y otros recursos gráficos utilizados en el videojuego pertenecen a la Universidad Técnica Particular de Loja (UTPL) y no se incluyen en este repositorio. El repositorio contiene únicamente el código fuente desarrollado para el proyecto.

Tecnologías

* Unity
* C#
* Git / GitHub

Sistemas desarrollados

El proyecto incluye diferentes sistemas y funcionalidades implementados mediante scripts de C#, entre ellos:

* Control y movimiento del personaje
* Sistemas de interacción
* Gestión del inventario
* Gestión de objetos
* Sistemas de enemigos y comportamiento
* Interfaz de usuario (UI)
* Diálogos y eventos
* Gestión de escenas
* Mecánicas del videojuego
* Gestión del estado del juego

Estructura del repositorio


La estructura de carpetas se mantiene para reflejar la organización utilizada durante el desarrollo del proyecto.

Objetivo

El proyecto tuvo como objetivo aplicar conocimientos de programación, desarrollo de videojuegos, diseño de sistemas interactivos y desarrollo con Unity y C#, integrando diferentes funcionalidades en un videojuego desarrollado como parte del proceso de titulación.
